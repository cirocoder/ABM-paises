# TP N.º 2 · Unidad 4 · Países

Alta de países con nombre obligatorio, modificación y baja con confirmación. El listado inicial incluye Chile, Perú y Uruguay.

## Ejecutar

Con Node.js 22.12 o superior, abrí una terminal en la carpeta del proyecto y ejecutá:

```sh
npm install
npm run dev
```

Abrí la dirección que muestra Vite en la terminal (normalmente http://localhost:5173).
Para compilar, usá `npm run build`.

Los cambios se guardan en `localStorage` y se conservan al recargar en el mismo navegador y puerto.
